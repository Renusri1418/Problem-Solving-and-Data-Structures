## Day 2 – Trees, Hashing, Graphs and Algorithmic Patterns

Day 2 introduces important data structures and algorithmic patterns through three practical problem sets.

### Set 1 – E-Commerce Catalogue and Traffic Analysis

- Binary Search Tree (BST): Insert and search product categories and perform inorder, preorder, and postorder traversals.
- Hash Tables: Implement collision handling using chaining and compare lookup performance with Python dictionaries.
- Graphs: Represent microservice dependencies and explore BFS, DFS, and circular dependency detection.
- Sliding Window: Identify the busiest continuous three-hour period.
- Two Pointers: Find pairs of sorted order values that match a target gift-card value.

### Set 2 – Insurance Claims Processing

- Binary Search Tree: Organize claim IDs and perform different tree traversals.
- Hashing: Identify duplicate and near-duplicate insurance claims.
- Graphs: Model claim-processing stages and explore paths using BFS and DFS.
- Sliding Window: Identify the longest consecutive run of days when claims exceed a specified threshold.
- Two Pointers: Merge two sorted claim lists without additional sorting.

### Set 3 – Logistics Network and Delivery Windows

- Binary Search Tree: Manage hub codes and analyze tree height.
- Hash Maps: Track parcel scans and identify repeated scans at the same hub.
- Graphs: Represent a logistics network using adjacency lists and find routes using BFS and DFS.
- Sliding Window: Find the four-hour period with the highest average parcel volume.
- Two Pointers: Check whether a delivery route is a palindrome while ignoring case and separators.

## How to Clone the Repository

Clone the repository to your local machine:

```bash
git clone https://github.com/Renusri1418/Problem-Solving-and-Data-Structures.git
```

Navigate into the project directory:

```bash
cd Problem-Solving-and-Data-Structures
```

## How to Run the Programs

1. Open the cloned project folder in Visual Studio Code.
2. Navigate to the required training day.
3. Open the relevant problem set.
4. Select the Python file you want to execute.
5. Run the following command in the terminal:

```bash
python filename.py
```

For example:

```bash
python Day-2/Set-01-Ecommerce-Catalogue/task1_bst.py
```
